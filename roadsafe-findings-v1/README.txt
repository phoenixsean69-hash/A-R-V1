RoadSafe AR — Forensic Findings V1

This is the screen after 2D / 3D / AR and before Report.

Flow
Evidence
→ Analysis
→ Hypotheses
→ Simulation
→ Canonical 2D / 3D / AR Reconstruction
→ Findings
→ Report

Adds
- Final Findings register
- Finding categories and dispositions
- Confidence
- Derived provenance only
- Supporting / conflicting physical evidence
- Supporting / conflicting Analysis findings
- Measurement links
- Hypothesis links
- Simulation run links
- Canonical reconstruction link
- Investigator rationale
- Limitations
- Unresolved questions
- Report-readiness status
- Include / hold / exclude controls
- Readiness matrix
- Legal-neutrality rule

Important forensic rule
Findings are derived conclusions. Observed and Measured records stay in their
original registers. A simulation or reconstruction is not silently converted
into an observed fact.

Install
1. Extract the ZIP.
2. Copy roadsafe-findings-v1 into:
   C:\Users\nooklyweb\Desktop\A-R-V1

3. Run from the A-R-V1 root:
   node .\roadsafe-findings-v1\install-forensic-findings-v1.mjs
   npm run build

Prerequisite
The Forensic 2D / 3D / AR screen must already be installed.
