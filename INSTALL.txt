RoadSafe AR UI shell restructuring

Run this from the repository root:

node install-roadsafe-ui-shell-restructure.mjs

The installer:
- backs up the current UI files;
- installs the new three-column workstation shell;
- adds the right-side case inspector;
- replaces the near-black/navy theme with the agreed gray and dull-blue palette;
- runs npm run build.

Then run:

npm run dev
